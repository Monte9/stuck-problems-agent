# Ledger

Incoming problem briefs, one file each: `YYYY-MM-DD-<kebab-slug>.md`.

The scout routine drops one here daily (`[scout]` commits). When no problem is active, intake promotes the newest unpromoted brief to `problems/<slug>/problem.md` and the loop takes it from there. Covered topics = everything in this directory plus everything in `problems/`.

This repo is the sole source of truth for briefs. There is no external ledger.
