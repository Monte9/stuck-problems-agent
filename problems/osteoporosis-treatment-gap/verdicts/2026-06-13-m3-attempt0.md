## Critique (FAIL only)
Two concrete fixes; everything else stands.

1. **Add a hip-fracture cost row to the inputs table.** The done-criteria require the inputs table to list "refracture and hip-fracture costs," each cited. You already have the figure in Section 5 prose (index hip fracture >$37,000 inpatient+SNF, Milliman 2021 Fig. 13) — promote it to an input row (e.g., I16, C_hip) with the Milliman citation. Either use it (e.g., a hip-weighted gross-savings variant: AF × h × C_hip + AF × (1−h) × C_nonhip) or state in one line why the model uses the blended C_sub instead. Presence in the table with a citation is what the criterion demands.

2. **Fix the high-scenario program cost.** Recompute targeted-outreach cost using the high scenario's own treatment gap: (0.68 − 0.211) × 1,148,000 ≈ 538,400 incremental treated × $105 ≈ $56.5M, giving net ≈ +$185M (not +$217M). Update the footnote, the table row, and any downstream mentions (Section 5 ROS comparison, the M4 forward pointer). Alternatively, if you intend the targeted FLS to contact only ~240,000 patients, you must state the inputs that produce that count — as written it contradicts the scenario's own r1.

No other changes needed: base/low arithmetic verifies exactly, sourcing and limitations are strong, and the net-cost honesty in Section 3 is a strength — keep it.
