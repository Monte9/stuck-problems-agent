## 4. Gaps and limitations / counter-evidence

**Concrete gaps (what the open-data landscape cannot currently do):**

1. **No per-event MARS notification/response data is public.** IMEO publishes only aggregate annual response statistics in *An Eye on Methane* (#13). I probed the IMEO data platform's API for notification/alert/case endpoints this session — all 404. M2's "MARS-notified / response status" column will therefore depend on statements in the annual report text, IMEO case-study writeups, and press coverage, not on a queryable log. This is itself a finding worth stating in M5.
2. **MethaneSAT is gone.** The mission failed in orbit in June 2025 ([Science, June 2025](https://www.science.org/content/article/methane-tracker-lost-space), via problem brief). Its planned basin-scale + point-source coverage is absent for 2025–2026 events; archived pre-failure data exists but was not verified this session and covers only ~1 year.
3. **GHGSat — the largest commercial point-source archive — is paywalled.** Only limited samples flow into public channels (e.g., ESA third-party-mission access for research). None of the rows above include it; the league table will systematically miss events seen only by GHGSat. [No GHGSat URL verified this session; excluded from the table for that reason.]
4. **Operator attribution is the weakest link, by design of the sources.** None of the plume datasets (#1–#4) carry an operator field. Attribution requires spatial join against OGIM (#5), whose operator attribute is strong in North America and sparse elsewhere (ESSD paper, #5) — precisely the regions (Turkmenistan, Algeria, Iran, Iraq, Libya) where TROPOMI sees the most persistent super-emitters. Expect a large "unattributed (no public facility ownership record)" tail in M2; the spec's allowance for explicit unattributed rows will be needed.
5. **IEA and UNEP block automated clients.** iea.org returned 403 in every attempt (5/5, multiple UAs); unep.org and methanedata.unep.org 403 the default fetch UA; eur-lex.europa.eu serves 202 anti-bot pages. Reproducible pipelines must use the blob-storage asset URLs, the Cellar, and browser UA strings — documented above so M2–M4 don't rediscover this.
6. **EU import statistics measure reported partner, not molecule origin.** Eurostat partner-country LNG data can hide transshipment/re-export origin, and some bilateral flows are confidential; ENTSOG measures network points, not exporters. M3 should triangulate Eurostat (#8) against Bruegel (#11) and ALSI (#10) and state residual uncertainty, especially for LNG of US vs. other Atlantic-basin origin and for Russian-origin molecules arriving via third countries.

**Counter-evidence and honest caveats against this inventory's own framing:**

- **"Open detections" are not uniformly trustworthy rankings inputs.** SRON's page itself warns plumes have "only been subject to initial verification" and excludes broad-area enhancements — so a league table built on these sources is biased toward point-source-style emitters in cloud-free, mid-latitude, onshore regions, and TROPOMI/EMIT geographic limits (EMIT only ±54° latitude, per CMR metadata fetched this session) exclude most high-latitude Russian infrastructure. A country looking "clean" in M2 may simply be unobservable.
- **The IMEO plumes API is undocumented.** It worked unauthenticated today, but there are no terms, no schema documentation, and no stability guarantee; M2 should snapshot any data it pulls and cite fetch dates.
- **Quantitative figures quoted from the problem brief** (e.g., MARS response rates of 1% in 2024 / ~12% in 2025; 35 Mt no-net-cost abatement) trace to *An Eye on Methane 2025* and the IEA GMT 2026 key-findings page. I verified those documents exist and are current, but did not re-extract the numbers from inside the PDFs this session; M2/M4 must verify them at point of use rather than inheriting them from this inventory.
- **Climate TRACE source-level numbers are modeled estimates**, not observations; its license is open but its oil-and-gas methane values can diverge substantially from both IEA inventories and satellite observations. It is included as a cross-check, not a primary detection source.
- **Sample-record dates don't establish archive bounds.** For #1 I verified one 2023 record; for #2 a 2026 record. Full temporal extents of the IMEO and Carbon Mapper archives were not enumerated (would require paging the APIs) — flagged here so M2 does that enumeration before claiming completeness for "2024–2026."
